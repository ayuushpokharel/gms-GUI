# 🏋️ Gym Management System

A web app to manage gym memberships, classes, and members — built with the MERN stack.

## What's inside

- Member registration, login, and profiles
- Browse and purchase memberships & classes
- Admin dashboard to manage everything
- Payments via Stripe, image uploads via Cloudinary
- BMI calculator

## Run it locally

```bash
# Install backend deps
npm install

# Install frontend deps
cd frontend && npm install

# Start backend
npm run dev

# Start frontend
npm start
```

Set up your `.env` in `backend/config/` with your MongoDB, Stripe, and Cloudinary credentials.
